# Interactive EDA App

## Overview
This project is a simple exploratory data analysis (EDA) web application built using Streamlit. 
The app allows users to explore relationships between variables in the dataset through interactive inputs and visualizations.

## Features
- Upload the data file or the default data is Iris dataset
- Select two variables from the dataset
- Select the hue variable
- Generate a scatter plot
- Calculate correlation between variables
- Show the relationship between variables
- Interactive web interface

## Dataset
The Iris dataset contains measurements of iris flowers including:
- Sepal length
- Sepal width
- Petal length
- Petal width

## Tool use
streamlit
pandas
matplotlib
seaborn

## Installation
Clone the repository:
`git clone <repo-url>`

Install dependencies:
`pip install -r requirements.txt`

## Run the App
`streamlit run app.py`
